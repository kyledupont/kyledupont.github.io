homelab · build log
2026-08-25

Deployed a Grafana + Prometheus + Node Exporter monitoring stack, Ansible-managed with the admin password in Ansible Vault and Prometheus auto-provisioned as Grafana's datasource via file-based config — no manual UI setup on first login. Lesson docker compose up -d only recreates a container when the compose file's own declared config changes — it can't see edits to the contents of a file already inside a bind mount, so a config-only change silently kept serving stale data through a "successful" CI deploy until a manual restart.

2026-07-28

Ran a real SQL deep dive against the lab's own Postgres instance — designed a multi-table homelab-inventory schema, proved indexing's impact with EXPLAIN ANALYZE on a synthetic 2-million-row table (46.9ms → 2.96ms, ~16x), and demonstrated row-level locking across two genuinely concurrent sessions. Lesson wrapping an indexed column in a function (col::date = ...) silently defeats the index — the same ~16x gap showed up again just from rewriting the query as a sargable range.

2026-07-28

Deployed Pi-hole for network-wide DNS and ad blocking, diagnosing a subtle failure where DNS queries reached the container fine but got silently ignored — root-caused to Pi-hole's own listening-mode config, not a firewall. Lesson a completed TCP handshake with no response points at the application silently filtering, not the network dropping it — a different failure class from "unreachable," with a different fix.

2026-07-26

Formalized a network isolation boundary — the media server VM is deliberately kept separate from the automation/control-plane host, so it can eventually be exposed to the internet without widening the blast radius of the machine holding SSH keys and CI credentials.

2026-07-24

Stood up a single-node K3s Kubernetes cluster (Terraform-provisioned, Ansible-bootstrapped), deployed and load-tested a real workload, then published the companion system map live on GitHub Pages.

2026-07-24

Lesson a "this text should read as secondary/quiet" design choice still needs an actual contrast-ratio check — this site's old faint text tier looked fine and measured 2.43:1 in light mode, well under WCAG AA's 4.5:1 minimum.

2026-07-23

Wired a self-hosted GitHub Actions runner to auto-deploy Ansible playbooks on every push, widened Ansible to a second host, and shipped the first production service (PostgreSQL) with secrets in Ansible Vault. Lessons NFS root-squash silently breaks containers that chown their own data directory on first boot; and Ansible's group_vars/<name>/ only loads for a group literally named <name>.

2026-07-22

Brought Terraform into the lab against the Proxmox API, working through real least-privilege token/ACL design split across compute, storage, and networking permission domains. Lesson Proxmox API tokens need their own explicit ACL grants across each domain — privilege separation means a token doesn't inherit its parent user's permissions.

2026-07-21

Closed out a batch of open items in one sitting — finished migrating the media library to TrueNAS, confirmed the /uptime-status slash command end-to-end, and traced a "slow" internet reading down to a single-threaded speed-test tool. Lesson single-connection speed tests badly understate real throughput above ~1 Gbps; a multi-stream tool is the only reliable read on a fast link.

2026-07-19

Wired this repo's docs to auto-mirror into an Obsidian vault on every commit via a git post-commit hook, and began connecting Claude Desktop's MCP access to that same vault.

2026-07-18

Built a custom Model Context Protocol (MCP) server and a full n8n automation workflow (job/learning/news digest), orchestrated with Claude. Lesson for a fast-moving SDK, trust the package registry's "latest" tag over a repo's default branch — the two can drift apart.

2026-07-17

Root-caused a network throughput bottleneck end-to-end — switch hardware, NIC negotiation, and a misleading single-threaded speed-test tool.

2026-07-15

Extended storage to a mirrored ZFS pool, added a second SSD for VM storage, stood up a single-pane Homepage dashboard, and upgraded Uptime Kuma across a major version bump.

2026-07-14

Stood up the lab's Proxmox foundation and first VMs, git-tracked as infrastructure-as-documentation from day one.
