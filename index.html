Recently Learned full log ↗

  • 2026-07-26

    A git push only updates GitHub — any self-hosted service reading from a local checkout still needs an explicit git pull on that host, and it's easy to assume "pushed" means "deployed."

  • 2026-07-24

    A "this text should read as secondary/quiet" design choice still needs an actual contrast-ratio check — the old faint text tier looked fine and measured 2.43:1 in light mode, well under WCAG AA's 4.5:1 minimum.

  • 2026-07-23

    NFS root-squash silently breaks containers that chown their own data directory on first boot — a trap for any containerized app on network-backed storage, not just Postgres.

  • 2026-07-23

    Ansible's group_vars/<name>/ only loads for a group literally named <name> — pointing it at a host with the same name does nothing, silently.

  • 2026-07-22

    Proxmox API tokens need their own explicit ACL grants across compute, storage, and network domains — privilege separation means a token doesn't inherit its parent user's permissions.

  • 2026-07-21

    Single-connection speed tests badly understate real throughput above ~1 Gbps; a multi-stream tool (Ookla CLI, iperf3 -P) is the only reliable read on a fast link.

  • 2026-07-18

    For a fast-moving SDK, trust the package registry's "latest" tag over a repo's default branch — the two can drift apart.
